Accessibility statement

Using this website

The flood and coastal erosion risk management projects and funding (FCERM) service is run by the Environment Agency. We want as many people as possible to be able to use this website. For example, that means you should be able to:

  • change colours, contrast levels and fonts
  • zoom in up to 200% without the text spilling off the screen
  • navigate most of the website using just a keyboard
  • navigate most of the website using speech recognition software
  • listen to most of the website using a screen reader (including the most recent versions of JAWS, NVDA and VoiceOver)

We have also made the website text as simple as possible to understand.

AbilityNet has advice on making your device easier to use if you have a disability.

How accessible this website is

We know some parts of this website are not fully accessible:

  • Some field sets are missing legends. The fields are still read by the screen reader but the user needs to navigate to them. [2.4.6 Headings and Labels - Date to fix - 01.09.2023]
  • When an error is generated the specific error field does not have the focus. Although the tab key can used it is confusing as a screen reader doesn't know where to move to. [2.4.7 Focus Visible - Date to fix - 01.09.2023]
  • Browsers cannot automatically suggest information to help a user fill in a form. This would be particularly helpful when filling in a manual address. [1.3.5 Identify Input Purpose - Date to fix - 01.09.2023]

Disproportionate burden

Non-accessible content - In the service we use PDF documents that are not fully accessible to screen reader software [2018 regulations].

What to do if you cannot access parts of this website

If you need information on this website in large print or braille:

  • email enquiries@environment-agency.gov.uk
  • call us on 03708 506 506 (Monday to Friday, 8am to 6pm)

We will consider your request and get back to you within 10 days.

Reporting accessibility problems with this website

We are always looking to improve the accessibility of this website. If you find any problems that are not listed on this page or think we are not meeting the requirements of the accessibility regulations, contact:

  • email enquiries@environment-agency.gov.uk
  • call us on 03708 506 506 (Monday to Friday, 8am to 6pm)

Enforcement procedure

The Equality and Human Rights Commission (EHRC) is responsible for enforcing the accessibility regulations. If you are not happy with how we respond to your complaint, contact the Equality Advisory and Support Service (EASS).

Technical information about this website's accessibility

The Environment Agency is committed to making its website accessible, in accordance with the Public Sector Bodies (Websites and Mobile Applications) (No. 2) Accessibility Regulations 2018.

Compliance status

This service is partially compliant with the Web Content Accessibility Guidelines version 2.1 AA standard, due to the non-compliances listed.

  • Some field sets are missing legends. The fields are still read by the screen reader but the user needs to navigate to them. [2.4.6 Headings and Labels - Date to fix - 01.09.2023]
  • When an error is generated the specific error field does not have the focus. Although the tab key can used it is confusing as a screen reader doesn't know where to move to. [2.4.7 Focus Visible - Date to fix - 01.09.2023]
  • Browsers cannot automatically suggest information to help a user fill in a form. This would be particularly helpful when filling in a manual address. [1.3.5 Identify Input Purpose - Date to fix - 01.09.2023]

How we tested this website

The service was last tested on 10th April 2023 and was checked for compliance with WCAG 2.1 AA.

It was tested by the FCRM development team, and the non-compliant elements will be included in the ongoing development work.

This statement was prepared on 12th May 2023.
